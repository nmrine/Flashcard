ทบทวนแฟลชการ์ด

ใน Quizlet: เปิดชุดการ์ด → ⋯ → ส่งออก → คัดลอกข้อความ แล้ววางด้านบน ภาษาของแต่ละด้านจะตรวจจับอัตโนมัติ (ไทย / อังกฤษ / ญี่ปุ่น) หรือเลือกเองในหน้าทบทวนได้

ยังไม่มีการ์ด ไปที่แท็บ “นำเข้า” ก่อน

คีย์ลัด: ช่องว่าง = พลิก, ← → = เลื่อน

คีย์ลัด: กด 1–4 เพื่อเลือกคำตอบ

โฟลเดอร์และบท

จัดบท (deck) ไว้ในโฟลเดอร์เพื่อความเรียบร้อย เช่น โฟลเดอร์ “JLPT N5” มีบทที่ 1, 2, 3 · ทุกบทใช้ช่องและแบบการ์ดร่วมกัน

ช่อง (Fields)

1 โน้ตมีได้หลายช่อง เช่น คันจิ / คำอ่าน / คำแปล แล้วกำหนดด้านล่างว่าการ์ดแต่ละแบบให้ด้านหน้า–หลังแสดงช่องไหน

แบบการ์ด (หน้า–หลัง)

โน้ต

ส่งออก

CSV: 1 บรรทัด = 1 โน้ต ทุกช่อง · JSON: เก็บช่อง แบบการ์ด และสถานะจำได้ครบ นำกลับเข้ามาได้ในแท็บนำเข้า

เกม

เลือกเกมที่ชอบ ข้อที่ตอบผิดจะถูกทำเครื่องหมาย “ยังไม่จำ” ในโหมดทบทวน

จับคู่แข่งเวลา

แตะคำศัพท์กับความหมายที่เป็นคู่กัน จับให้ครบเร็วที่สุด ผิดโดนบวกเวลา 2 วินาที

พิมพ์จำ

เห็นโจทย์แล้วพิมพ์คำตอบเอง ข้อที่ผิดจะวนกลับมาถามใหม่ การดึงคำตอบออกมาจากความจำเองช่วยให้จำได้นานกว่าการเลือกตอบ

จริงหรือหลอก
